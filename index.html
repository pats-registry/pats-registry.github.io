03 / how the registry works
⌘

Install from source

Kirn uses the Pets registry as a discovery and install source, so packages stay close to the code you can review.

kirn install your-pet
▦

One clear index

registry.toml keeps the official list machine-readable, searchable, and easy for tooling to consume.

registry.toml → Kirn
↗

Build everywhere

Standard Pets are automatically built and released for every supported platform as the registry evolves.

push → build → release
